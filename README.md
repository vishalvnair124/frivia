# ❓ Frivia – Flutter Quiz App

**Frivia** is a simple and interactive **quiz app** built with **Flutter**, using the [OpenTDB API](https://opentdb.com/api.php) to fetch trivia questions.

---

## 🎯 Features

- 🎲 Multiple-choice trivia questions from OpenTDB  
- 📱 Cross-platform support: Android, iOS, Web, Desktop  
- 🧠 Tracks and displays quiz score  
- 🎨 Custom font (`ArchitectsDaughter`) for fun UI

---

## 🧑‍💻 Tech Stack

- **Frontend:** Flutter (Dart)  
- **API Source:** OpenTDB (https://opentdb.com/api.php)  
- **Font:** Custom Google Font (`assets/fonts/ArchitectsDaughter-Regular.ttf`)

---

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/vishalvnair124/frivia.git
cd frivia
```

2. Get dependencies:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run
```
